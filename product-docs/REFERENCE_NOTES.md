# Reference Notes

The original reference informed the **delivery pattern**: an independently hosted configurator embedded on a manufacturer's site, with save/share/print and a 3D product.

This package is aimed at **supplier manufacturers issuing Revit families**. Browser code authors type catalogs, shared parameters and a family spec. A production Revit job, not the browser, writes `.rfa` files.

The only third-party runtime copied into the package is Three.js, which retains its own license notice.
