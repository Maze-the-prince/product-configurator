# Sales Demo Checklist

## Before the meeting

- Set manufacturer name, family name and accent in `/admin`.
- Confirm category (Specialty Equipment vs Mechanical Equipment) matches their library.
- Decide whether to show AR or stay on BIM downloads.
- If the client already has `.rfa` files, say the configurator drives types of those families.

## 5-minute presentation

1. **30 sec — Problem:** manufacturers email zip files of families; specifiers explode them or request yet another type.
2. **60 sec — Configure:** width, finish, base, nested hood — type name updates.
3. **45 sec — BIM:** OmniClass, MasterFormat, LOD 350 connectors.
4. **45 sec — Downloads:** type catalog + shared parameters + family spec JSON.
5. **45 sec — Lead:** request `.rfa` with Revit 2025 and a project name.
6. **45 sec — Portal:** identity fields, specifier leads, embed on the BIM library page.
7. **30 sec — Factory:** production writes the actual `.rfa` from this spec.

## Discovery questions

- How many product families and types do you maintain in Revit today?
- Which Revit years must you support?
- Specialty Equipment, Mechanical Equipment, or mixed categories?
- Face-based, level-hosted, or work-plane families?
- Do you already have a shared parameter file with stable GUIDs?
- Nested families vs visibility parameters?
- Should specifiers download BIM only, or also request a quote?
- ACC / BIM 360 library publish, or website download?
- Who owns OmniClass / IFC mapping after launch?
